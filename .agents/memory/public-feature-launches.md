---
name: Public feature launch messaging
description: Scope and language requirements for promoting AI Observly feature launches.
---

Feature launch updates belong on the public website, blogs, and other public pages, not the dashboard.

**Why:** The user explicitly said, “Only on the website and blogs and other website pages, no changes in the dashboard.”

**How to apply:** Keep launch-marketing changes separate from authenticated product functionality unless the user explicitly expands the scope.

Describe launched features in non-technical language that non-technical personas can understand.

**Why:** The user explicitly requires understandable messaging for non-technical readers.

**How to apply:** Explain repeated-work savings, response speed, and failed or incomplete answers through business outcomes; avoid raw field names and unexplained engineering terms. Do not invent guaranteed savings or plan entitlements.
