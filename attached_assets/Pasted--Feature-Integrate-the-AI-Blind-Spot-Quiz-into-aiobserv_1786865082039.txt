# Feature: Integrate the AI Blind Spot Quiz into aiobservly.com

## Overview
We're adding a second free lead-magnet tool — the **AI Blind Spot Quiz** — alongside the existing LLM Spend Analyzer (`/spend-checkup`). Unlike the Spend Analyzer, this tool takes no file uploads and needs **no database, no server-side logic, and no API calls** — it's a fully self-contained, client-side quiz (HTML/CSS/JS provided in the attached file `find-your-ai-blind-spot-quiz.html`).

This doc covers four changes: a new page, a homepage tile, a nav update, and a blog CTA update.

---

## 1. New page: `/blind-spot-quiz`

- **Route:** `/blind-spot-quiz`
- **Build pattern:** Set this page up the same way `/spend-checkup` is currently built — same header/nav + footer shell, with the interactive tool mounted as the page's main content.
- **Widget code:** Port the markup, `<style>`, and `<script>` from `find-your-ai-blind-spot-quiz.html` into this page's component. It's fully self-contained — no props, no external data, no backend calls. Before shipping, replace the placeholder `PRODUCT_URL` constant near the top of the script with the real signup/pricing URL.
- **No database, no CSV upload, no email gate** — this tool is intentionally pure frontend state. Don't wire it into Resend or any storage.

### SEO / meta tags
Keep these distinct from `/spend-checkup`'s meta tags (which should stay targeted at more technical, "upload your OpenAI/Gemini bill" style queries). This page targets a more emotional, top-of-funnel search intent:

- **Title:** `Am I Losing Money on AI? | Free Blind Spot Quiz`
- **Description:** `Take our free 90-second quiz to find your AI cost blind spots — see if you know what you're really spending, and whether it's actually profitable.`
- Add matching Open Graph / Twitter card tags (same title/description) so it previews well when shared or linked from blog posts.
- Add `/blind-spot-quiz` to `sitemap.xml` wherever `/spend-checkup` is currently listed.

## 2. Homepage: tile below the core Features section

Add a single promotional card directly **below the Features section**, before whatever section currently follows it.

- Keep it lightweight — one card, not a new multi-column section, so it doesn't compete visually with Features above or Pricing/testimonials below.
- Content: short headline (e.g. "Not sure where your AI budget is going?"), one line of supporting copy, and a button — **"Take the free quiz →"** — linking to `/blind-spot-quiz`.

## 3. Nav: replace "Free Spend Checkup" with a "Free Tools" dropdown

Currently the nav has a single top-level `Free Spend Checkup` link. Replace it with:

- **"Free Tools"** — a hover dropdown, reusing the same dropdown component already built for **"Blogs"** in the nav, for visual and interaction consistency.
- Two entries inside it:
  - **Your AI Blind Spot Quiz** → `/blind-spot-quiz`
  - **LLM Spend Analyzer** → `/spend-checkup`

This keeps the nav at 5 top-level items (Products, Docs, Blogs, Pricing, Free Tools) rather than growing to 6, and leaves room to add a third free tool later without another nav change.
