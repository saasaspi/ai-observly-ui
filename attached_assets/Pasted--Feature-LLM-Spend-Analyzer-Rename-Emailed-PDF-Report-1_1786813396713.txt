# Feature: LLM Spend Analyzer Rename + Emailed PDF Report

## 1. Rename the tool sitewide
Rename "AI Spend Check-up" / "Spend Check-up" to **"LLM Spend Analyzer"** everywhere it appears:
- Page H1 and any subheading copy on the tool page
- Page `<title>` tag and meta description (should be unique to this page, not inherited from the homepage)
- Homepage nav link ("Free Spend Check-up" → "Free LLM Spend Analyzer")
- Footer link under Resources
- Keep the existing URL `/spend-checkup` as-is for now (no need to change routes) — just update all visible text and internal link labels to the new name.

## 2. Add the "Download this report PDF" button
- Place a button labeled **"Download this report PDF"** on the results view — i.e., after a user has uploaded their CSV and the spend breakdown is already showing on screen.
- On click, open a modal/dialog with:
  - A single email input field
  - Basic client-side email format validation
  - A submit button labeled **"Email me my report"**
  - A cancel/close option
- On successful submission, show a confirmation state in the modal: "Report sent! Check your inbox." Handle and display a friendly error message if the request fails (e.g., "Something went wrong — please try again.").

## 3. Backend endpoint
Create a new backend endpoint (e.g. `POST /api/send-report`) that accepts:
- The user's email address
- The already-computed report data (the same breakdown values currently rendered on screen — no need to re-parse the CSV server-side)

The endpoint should:
1. Validate the email format server-side (don't rely on client-side validation alone).
2. Generate a branded PDF from the report data (see branding spec below).
3. Send that PDF via the Resend API (see section 4).
4. Return a simple success/failure response to the frontend.

Rate-limit this endpoint per email/IP (e.g., max 3–5 requests per address per hour) to prevent abuse, since it's a public, no-signup-required endpoint.

## 4. PDF generation — AI Observly branding
The PDF must look like an official AI Observly document, not a plain data dump. Include:
- **AI Observly logo** at the top of the first page (pull from the existing logo asset already used on the site/homepage)
- Report title: **"LLM Spend Analyzer Report"**
- Generated date/timestamp
- The site's existing blue-and-white color theme for headers, section dividers, and accents
- The same spend breakdown sections/numbers currently shown in the on-screen results (totals, per-provider breakdown, etc. — mirror whatever the tool already displays)
- A footer with "Generated by AI Observly — aiobservly.com" and a short CTA line, e.g. "Want to track this automatically? Start monitoring at aiobservly.com"

**Implementation note:** favor a lightweight PDF-generation approach that doesn't require a full headless browser (avoid Puppeteer/Playwright if possible — heavy on a Replit-hosted app). If the codebase is Node/React-based, `@react-pdf/renderer` is a good fit — it supports images (for the logo) and custom styling without needing a browser engine. If the stack is different, use whichever standard PDF library fits it, but keep the same requirement: logo + brand colors + structured sections, generated server-side, no headless browser dependency if avoidable.

## 5. Sending the email via Resend
- Domain `aiobservly.com` is already verified on Resend (DKIM, SPF, DMARC all confirmed) — sending is unrestricted.
- Send **from**: `noreply@aiobservly.com`
- Send **to**: the email the user submitted
- Subject: "Your LLM Spend Analyzer Report"
- A short plain HTML body (1–2 sentences, branded tone) — e.g. "Here's your LLM spend report from AI Observly. Have questions about optimizing these costs? Just reply to this email— wait, actually since this is noreply, skip that line and instead say: "Want automatic tracking instead of one-off checkups? Visit aiobservly.com/pricing."
- Attach the generated PDF using the `content` field (base64/buffer of the freshly generated PDF), not `path` — each report is unique per user, so there's no static file to link to.
- Use the Resend API key from an environment variable / Replit Secret (`RESEND_API_KEY`) — never hardcode it in the code.

## 6. Small copy update
Since the report data now leaves the browser (to generate the PDF and email it), update the existing privacy line on the tool page from:
> "Your file is processed entirely in your browser — it's never uploaded anywhere."

to something like:
> "Your CSV is processed entirely in your browser and never uploaded. Only the report you choose to email is sent, and only to the address you provide."
