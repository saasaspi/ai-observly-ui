## Setup Steps

1. **Install the SDK**, pinned to the current major version:
   `npm install @amplitude/unified@^1`

2. **Store the API key using Replit's Secrets tool** (the padlock icon in the sidebar) — do not hardcode it in a file:
   - Add a secret named `NEXT_PUBLIC_AMPLITUDE_API_KEY` with value: `341a13c41d0d0c444c9ece14f393935e`
   - This project is Next.js, so the `NEXT_PUBLIC_` prefix is required for the value to be exposed client-side — Next.js inlines prefixed vars at build time. A plain `AMPLITUDE_API_KEY` secret (no prefix) would stay server-only and the browser SDK would never see it.
   - Guard the init call against a missing key, since a prefixed var unset at build time fails silently:
     `if (!process.env.NEXT_PUBLIC_AMPLITUDE_API_KEY) console.warn('Amplitude API key missing — analytics disabled');`

3. **Create a dedicated Client Component for the init logic.** Next.js renders Server Components by default, and the browser SDK can only run client-side — so this cannot live directly in a Server Component. Create a small component (e.g. `components/AmplitudeInit.tsx`) starting with `'use client'` on the first line, with a namespace import inside it:
   `import * as amplitude from '@amplitude/unified';`

4. **Initialize once**, using `initAll` (not `init` — that's a different, analytics-only entry point and is not acceptable here). Call it inside the Client Component from step 3, guarded so it only fires once even with React Strict Mode's double-render in development:
   `amplitude.initAll(process.env.NEXT_PUBLIC_AMPLITUDE_API_KEY, {"analytics":{"autocapture":true},"sessionReplay":{"sampleRate":1}});`

   Check whether this project uses the App Router or Pages Router before deciding where to mount the component: App Router → render it once from `app/layout.tsx`; Pages Router → render it once from `pages/_app.tsx`.
